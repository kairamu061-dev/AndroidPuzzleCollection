# BUG-001: ノノグラムのマスが押しにくい

- **State**: Fixed
- **Reported**: 2026-10-31（user）
- **Area**: `docs/nonogram/screen`, `app/.../nonogram/NonogramRoute.kt`
- **Rank**: C（遊べるが操作しづらい。誤操作の頻度が分かれば見直す）
- **Type**: 仕様

## Summary

実機でノノグラムのマスが「ちょっと押しにくい」と報告があった。

## Reproduction

こちらでは再現していない（実機が無い）。サイズと端末は未確認。

1. ノノグラムを開始する
2. マスを押す・なぞる
3. 狙ったマスを押しにくい（ユーザの報告）

## Expected

狙ったマスを無理なく押せる。

## Measured / Inferred

| | 測った（根拠） | 推測（何が分かれば決まるか） |
|---|---|---|
| 症状 | ユーザの報告「ちょっと押しにくいかな」。サイズは 15×15 と確認した | — |
| 原因 | 幅 360dp の描画で 15×15 のマスは約 20dp（`GameScreenshots` の画像で 39px / xhdpi）。プロジェクトの基準 48dp の半分以下 | マスの小ささが主因。誤って隣を押すのか、なぞりが効かないのかの確認で決まる |
| 影響 | — | 15×15 が遊びにくい。5×5 と 10×10 への影響は未確認 |

## Cause

**推測:** 盤面全体を 1 画面に固定で収める設計のため、大きいサイズでマスが小さくなる。
`docs/nonogram/screen/overview.md` でピンチズームを作らないものにしていた。

## Fix Decision

- **判定**: ユーザー判断
- **ユーザー判断**: 修正する — 2026-10-31、拡大機能を入れてよいとの回答

### 修正の影響

| 観点 | 内容 |
|---|---|
| 何を変えるか | 2 本指で拡大・移動できるようにする。1 本指は今までどおり塗る。拡大中もヒントが見えるよう、ヒントを画面端に固定する |
| 壊しうるもの | なぞり操作、座標からマスへの変換（`NonogramLayout`）。自動テストで守れる |
| 触れる他の機能 | ノノグラムの画面のみ |
| 工数の目安 | 中。盤面の描画とタッチ処理の書き直しを含む |
| 直さない場合 | 15×15 が押しにくいまま残る。10×10 までなら影響は小さいと見ている（推測） |

## Fix

2 本指で最大 4 倍まで拡大・移動できるようにし、ヒントを端に固定した。2 本目の指が触れたら 1 本目の塗りを取り消す。
あわせてユーザの判断でサイズを 20×20 のみとした（等倍のマスは幅 360dp で約 15dp）。**測った:** 最大倍率で約 60dp（画面の撮影）。
実機での押しやすさは未確認なので `Closed` にはしない。

- **Fix commit**: 302eadc
