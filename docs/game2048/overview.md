# 2048 概要

## 目的・背景

スワイプだけで遊べるスコアゲーム。論理パズルとは違う遊び方を足す。

## スコープ

### 作るもの

- 4×4 の 2048
- スコアとベストスコア
- 自動保存と再開
- 2048 到達後も続けられる

### 作らないもの

- 盤面サイズの変更
- Undo
- 時間の計測

## 制約

- 実行にネットワークを要しない

## 完了条件

- サブ項目の自動テストが通り、E2E が実機で確認済みである
