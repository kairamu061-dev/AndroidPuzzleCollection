# 2048 の画面 仕様

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | スワイプ | 4 方向の操作 | I-01, E-01 |
| 2 | スコア表示 | スコアとベスト | I-01 |
| 3 | タイルの動き | id をキーに位置をアニメーションする | E-01 |
| 4 | 達成の表示 | 続けるボタン | I-02 |
| 5 | 終了の表示 | 新しいゲームボタン | I-03 |
| 6 | 再開 | 開くと前回の盤面 | I-04, E-02 |
| 7 | 新しいゲーム | 進行中は確認する | I-05 |
