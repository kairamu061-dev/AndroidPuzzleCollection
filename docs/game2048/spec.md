# 2048 仕様

規則: スワイプで全タイルを同じ方向へ寄せる。同じ数字がぶつかると 1 つに合体して足し算になる。1 手ごとに新しいタイルが出る。動かせなくなると終了。

## 機能一覧

機能一覧はサブ項目の spec.md に置く。

- [logic](./logic/spec.md)
- [screen](./screen/spec.md)
- [save](./save/spec.md)

## 画面・操作フロー

1. ホーム → プレイ画面（前回の続き、無ければ新しいゲーム）
2. スワイプで動かす
3. 2048 到達で一度だけ達成の表示。続けられる
4. 動かせなくなると終了の表示
