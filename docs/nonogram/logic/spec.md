# ノノグラムのロジック 仕様

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | ヒント | 正解からヒントを作る | U-01 |
| 2 | 解法 | 行と列の確定だけで解く | U-02, U-03, U-04 |
| 3 | 4 | 操作 | 最初のマスで塗る / 消すを決め、なぞった分に同じ操作をする | U-08 |
| 5 | 1 操作 | 1 回のなぞりが Undo 1 回分 | U-09, U-10 |
| なぞりの取り消し | 途中のなぞりを無かったことにする | U-14 |
| 6 | 完成 | 塗りが正解と一致。×は見ない | U-11, U-12 |
| 7 | ヒントの完了表示 | その行の塗りがヒントと一致したら薄くする | U-13 |
