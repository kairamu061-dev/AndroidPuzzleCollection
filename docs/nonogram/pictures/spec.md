# ノノグラムの絵の問題集 仕様

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | 問題データ | 100 問。各問は ID・名前・20×20 の絵 | U-01, U-02 |
| 2 | 解ける保証 | 全問が行と列の確定だけで絵と一致する | U-03 |
| 3 | 次の問題 | 未完成のうち最初の問題。全部完成なら無し | U-04 |
| 5 | 対称の上限 | 左右対称の問題は全体の 10% まで | U-06 |
| 4 | 進捗 | 完成した絵の ID を保存する。問題集に無い ID は読み飛ばす | U-05 |

## 選定の基準

- 変換後に論理だけで解き切れる。黒の割合が 65% 以下
- 2 問の差が 45 マス未満の組を作らない（似た絵を避ける）
- 何の絵か読める（目視。判定は主観）
- 左右対称の問題は全体の 10% まで（2026-10-31 ユーザの判断）。対称度 0.95 以上を対称と数える。対称度は塗りマスのうち左右の鏡像も塗りである割合（中心のずれ 1 マスまで許す）
- 絵を傾けて対称を崩す方法は使わない。絵そのものが非対称なものを選ぶ

## 未対応ケース

- 難易度順の出題。順番は固定のシャッフルで、カテゴリが混ざるようにした
