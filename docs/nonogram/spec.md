# ノノグラム 仕様

規則: 行と列の数字は、その並びで連続して塗るマス数を順に表す。かたまりの間は 1 マス以上空ける。問題は推測なしに論理だけで解けるものだけを出す。

## 画面・操作フロー

1. ホーム → 開始画面（続きから / 次の絵 / 完成した絵の一覧）
2. マスを押す・なぞる
3. 全部塗れると絵の名前と時間が出て、記録される
4. 完成した絵は一覧から遊び直せる
