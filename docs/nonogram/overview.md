# ノノグラム 概要

## 目的・背景

行列の数字から絵を塗り出すパズル。解く楽しさと完成の達成感があり、数独とは違う論理を使う。

## スコープ

### 作るもの

- 20×20 の問題を端末内で生成
- 塗る・×印、ドラッグでまとめて塗る、Undo/Redo
- 経過時間、自動保存と再開

### 作らないもの

- 手作りの絵の同梱（問題は自動生成の模様）
- カラーのノノグラム
- ヒント機能、間違いの指摘

## 制約

- 実行にネットワークを要しない

## 完了条件

- サブ項目の自動テストが通り、E2E が実機で確認済みである

## 画面イメージ

```
+---------------------------+
| ←  20×20           03:25  |
+---------------------------+
|        1 3 2 1 ...        |
|  2 1 [ ][■][■][×] ...     |
|    4 [ ][ ][ ][ ] ...     |
+---------------------------+
| [戻す][進む][塗る / ×]    |
+---------------------------+
```
