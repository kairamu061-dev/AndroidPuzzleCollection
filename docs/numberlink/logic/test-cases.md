# ナンバーリンクのロジック テストケース

## ユニットテスト

| ID | テスト名 | 入力 / 条件 | 期待結果 | ステータス |
|----|---------|------------|---------|-----------|
| U-01 | 唯一解 | 解が 1 つの既知の盤面 | 1 | [x] |
| U-02 | 解が 2 つ | 解が 2 つの既知の盤面 | 2（対照: U-01） | [x] |
| U-03 | 総当たりとの照合 | 4×4・5×5 の無作為な端点配置 数百件 | 刈り込みありと総当たりの個数が上限 2 まで一致 | [x] |
| U-04 | 探索の上限 | 極端に小さい上限 | `null`（唯一と扱わない） | [x] |
| U-05 | 生成の保証 | 各サイズ × シード 30 | 解法で 1、線の長さが 3 以上、全マスを覆い、解の線が操作の規則でもクリアになる | [x] |
| U-06 | 再現性 | 同じシード / 別のシード | 同一 / 別 | [x] |
| U-07 | 所要時間 | U-05（JVM 上） | 1 問あたり最大 5 秒未満。受理率も出す | [x] |
| U-08 | 開始 | 端点 / 線の途中 / 空きマス | 線が始まる / そこから先が消える / 何もしない | [x] |
| U-09 | 延ばす | 隣へ 3 マス、相手の端点に着いた後さらに隣へ | 延びる / 止まる | [x] |
| U-10 | 縮める | 自分の線の 2 マス前へ戻る | そこまで縮む | [x] |
| U-11 | 切る | 他の色の線の途中へ入る | その線が入った場所から先で消える | [x] |
| U-12 | 飛び越し | 2 マス離れたマスへ | 無視される | [x] |
| U-13 | 1 操作 | なぞって Undo / 変化なし | 元に戻る / 履歴が増えない | [x] |
| U-14 | クリア | 解どおり / 2 解の盤面で保存した解と別の解 | 真 / 真 | [x] |
| U-15 | 空きマス | 全ペアがつながり 1 マス空き | 偽。空きマスがあることを状態から取れる | [x] |

## ステータス凡例

- `[ ]` 未実施
- `[~]` 実施中
- `[x]` 合格
- `[!]` 不合格
- `—` 対象外（差し替え・撤去など。理由を添える）

## 判定の注意

<!-- ここは消さずに残す。実際に判定を誤らせた形だけを書いてある -->

- **`0` を期待する項目には対照を置く。**「出なかった」は、**安定していた**のと
  **そもそも通っていない**のと区別が付かない。`1` になる場面を隣に置くか、
  数えている文字列が**実行ファイルの中にあること**を確かめる
- **「無いこと」を見る項目は、探し方が当たっているかを先に確かめる。**
  同じ探し方で「ある」ものを 1 つ挙げる。パスを間違えていれば、
  前も後も「無い」と出て、確認そのものが空になる
- **強い測り方に書き換える。**「見えていた」で通した項目は、次の回で弱いまま戻る。
  画素・ハッシュ・窓ハンドルで測れたなら、**その手順をここに書き写す**
- **1 つの操作を複数の窓口から見ている項目は、そう書く。**
  独立した N 件ではないので、「N 件通った」と数えない
