# ナンバーリンクのロジック 概要

## 目的・背景

唯一解の問題を作る生成と、なぞり操作の状態遷移を純粋ロジックにする。
解の個数の判定が誤ると、2 通り解ける問題が黙って出る。ここが最重要。

## スコープ

### 作るもの

- 解の個数を上限付きで数える解法
- 唯一解の問題の生成
- 線の操作（引く・縮める・切る）、Undo/Redo、クリア判定

### 作らないもの

- 描画

## 制約

- Android に依存しない純粋な Kotlin で書く（`:numberlink-core`）
- 生成は取り消せる。探索の途中でも取り消しを確かめる

## 完了条件

- `test-cases.md` の自動テストが通る
