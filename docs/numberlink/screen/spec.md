# ナンバーリンクの画面 仕様

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | 開始画面 | サイズの選択と続きから | I-01 |
| 2 | 盤面 | 端点に数字を書き、線を数字ごとの色で描く。色だけで区別させない | E-01 |
| 3 | なぞり | 押した場所から線を引く・縮める・切る | I-02, E-02 |
| 4 | Undo / Redo | 1 回のなぞりを戻す | I-03 |
| 5 | 空きマスの表示 | 全ペアがつながったのに空きマスが残るとき、その旨を出す | I-04 |
| 6 | クリア | 所要時間を出し、保存を消す | I-05 |
| 7 | 再開 | 続きから | I-06, E-03 |
