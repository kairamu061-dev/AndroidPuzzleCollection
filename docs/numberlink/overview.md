# ナンバーリンク 概要

## 目的・背景

指でなぞって線を引くパズル。収録済みのゲーム（数字を入れる・並べ替える・合体させる・塗る）に無い遊び方を足す。
問題は端末内で生成し、オフラインで無限に遊べる。

## スコープ

### 作るもの

- 正方形の盤面のナンバーリンク。サイズは 3 段階（具体的な値は生成の測定で決める。`logic/dev-notes.md`）
- 唯一解の問題の生成
- なぞって線を引く・縮める・切る、Undo/Redo、経過時間、自動保存と再開

### 作らないもの

- 斜めの線、ブリッジ、六角形の盤面などの変形ルール
- ヒント機能

## 制約

- 実行にネットワークを要しない
- 問題生成で画面を止めない

## 完了条件

- サブ項目の自動テストが通り、E2E が実機で確認済みである
