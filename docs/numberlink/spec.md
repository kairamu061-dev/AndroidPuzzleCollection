# ナンバーリンク 仕様

規則（このゲームで判定に使う唯一の定義。生成・解の数え上げ・クリア判定はすべてこれに従う）:

1. 同じ数字の 2 マス（端点）を、縦横に隣り合うマスを通る 1 本の線でつなぐ
2. 線は交差せず、枝分かれせず、他の数字のマスを通らない
3. **すべてのマスをいずれかの線が通る**
4. 問題の解はちょうど 1 つ

## 画面・操作フロー

1. ホーム → 開始画面（続きから / サイズの選択）
2. 端点か線の端からなぞって線を引く
3. 全ペアがつながり全マスが埋まるとクリアの表示
