# 数独 仕様

ルール: 各行・各列・各ブロックに 1〜9 を 1 つずつ入れる。

## 機能一覧

テストケース列の前半はサブ項目の名前。ID はそのサブ項目の `test-cases.md` のもの。

## 画面・操作フロー

1. ホームで数独を押す → 開始画面
2. 難易度を選ぶ（または「続きから」）→ 生成中の表示 → プレイ画面
3. 解き切るとクリアの表示 → 「新しいゲーム」で開始画面へ、または「ホームへ」
4. 途中で戻ると開始画面へ。状態は保存されている

画面ごとの詳細は `docs/sudoku/screen/spec.md`。

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| 中断データが壊れている・古い形式 | データ無しとして扱い、「続きから」を出さない |
| 保存に失敗した（容量不足など） | プレイは続行できる。再開できない可能性が残る（将来の課題） |

## 未対応ケース

- 複数ゲームの並行保存（中断データは 1 件のみ）
- アプリのプロセスが落ちた後の Undo 履歴の復元（履歴は保存しない）
