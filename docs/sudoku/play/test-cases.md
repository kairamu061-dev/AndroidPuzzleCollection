# 数独のプレイ状態 テストケース

## ユニットテスト

| ID | テスト名 | 入力 / 条件 | 期待結果 | ステータス |
|----|---------|------------|---------|-----------|
| U-01 | 記入 | 空きマスに数字 | 値が入り Undo が 1 件増える | [x] |
| U-02 | 初期マスの保護 | 初期マスに記入・メモ・消去 | 状態が変わらない | [x] |
| U-03 | 同じ数字で消える | 同じ数字を 2 回記入 | 空きに戻る | [x] |
| U-04 | メモの出し入れ | メモモードで同じ数字を 2 回 | 追加され、消える | [x] |
| U-05 | 記入済みマスへのメモ | 記入済みのマス | 状態が変わらない | [x] |
| U-06 | メモの自動整理 | 同じ行・列・ブロックと、無関係なマスに同じ数字のメモ | 関連マスのメモだけ消え、無関係なマスのメモと他の数字は残る | [x] |
| U-07 | 消去 | 記入あり / メモあり / 空 | 消える / 消える / 履歴が増えない | [x] |
| U-08 | Undo / Redo | 記入で U-06 の整理が起きた後に Undo、Redo。Undo 後に別の操作 | メモごと戻る、進む。別の操作で Redo が空になる | [x] |
| U-09 | 衝突 | 行のみ / 列のみ / ブロックのみの重複。対照: 重複なし | 重複した 2 マスだけ / 空 | [x] |
| U-10 | 残り個数 | 途中の盤面、10 個目の記入 | `9 − 個数`、下限 0 | [x] |
| U-11 | クリア判定 | 全マス正解 / 1 マス空き / 全部埋まっているが解と不一致 | 真 / 偽 / 偽 | [x] |
| U-12 | クリア後の操作 | クリア後に記入・消去・Undo | 状態が変わらない | [x] |
| U-13 | タイマー | 開始〜一時停止〜再開。二重の開始・一時停止 | 止まっている間は増えない。二重呼び出しで狂わない | [x] |
| U-14 | 未選択での操作 | 選択なしで記入・メモ・消去 | 状態が変わらない | [x] |
| U-15 | 解と違う数字 | 衝突しない誤った数字 | 受け付け、衝突にも出ない | [x] |

## ステータス凡例

- `[ ]` 未実施
- `[~]` 実施中
- `[x]` 合格
- `[!]` 不合格
- `—` 対象外（差し替え・撤去など。理由を添える）

## 判定の注意

<!-- ここは消さずに残す。実際に判定を誤らせた形だけを書いてある -->

- **`0` を期待する項目には対照を置く。**「出なかった」は、**安定していた**のと
  **そもそも通っていない**のと区別が付かない。`1` になる場面を隣に置くか、
  数えている文字列が**実行ファイルの中にあること**を確かめる
- **「無いこと」を見る項目は、探し方が当たっているかを先に確かめる。**
  同じ探し方で「ある」ものを 1 つ挙げる。パスを間違えていれば、
  前も後も「無い」と出て、確認そのものが空になる
- **強い測り方に書き換える。**「見えていた」で通した項目は、次の回で弱いまま戻る。
  画素・ハッシュ・窓ハンドルで測れたなら、**その手順をここに書き写す**
- **1 つの操作を複数の窓口から見ている項目は、そう書く。**
  独立した N 件ではないので、「N 件通った」と数えない
