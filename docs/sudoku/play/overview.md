# 数独のプレイ状態 概要

## 目的・背景

盤面への操作を画面から切り離す。記入・メモ・Undo は組み合わせの境目で壊れやすく、
実機で全部試すのは現実的でないため、純粋な状態遷移として書いて網羅的にテストする。

## スコープ

### 作るもの

- 盤面の状態と操作（選択・記入・メモ・消去・Undo/Redo）
- 衝突・残り個数・クリアの算出
- 経過時間の計測

### 作らないもの

- 描画、永続化

## 制約

- Android に依存しない純粋な Kotlin で書く

## 完了条件

- `test-cases.md` の全件が通る
