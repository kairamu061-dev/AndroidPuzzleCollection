# 数独の保存と再開 概要

## 目的・背景

スマホのゲームはいつ中断されるか分からない。保存の操作を要求せず、
いつ閉じても続きから遊べるようにする。

## スコープ

### 作るもの

- 進行中の 1 ゲームの直列化と端末内への保存
- 読み込みと、読めない場合の扱い

### 作らないもの

- 複数ゲームの保存、クラウド同期
- Undo 履歴の保存

## 制約

- 書き込みの途中でプロセスが落ちても前回の保存を壊さない
- UI スレッドでファイルを読み書きしない

## 完了条件

- アプリを終了して起動し直しても、盤面・メモ・経過時間が戻る
- 壊れたファイルでクラッシュしない

## 画面イメージ

画面は持たない。「続きから」の表示は `docs/sudoku/screen/spec.md`。
