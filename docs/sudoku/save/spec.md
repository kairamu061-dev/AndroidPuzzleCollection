# 数独の保存と再開 仕様

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | 保存内容 | 問題（初期配置・解・難易度）、記入、メモ、経過時間 | U-01, U-04 |
| 2 | 読み込み | 保存内容を復元する。選択はなし、メモ切り替えはオフ、履歴は空で始まる | U-01, I-01 |
| 3 | 読めないデータ | 壊れている・未知の形式なら「データ無し」として扱う | U-02, U-03, I-02 |
| 4 | 削除 | クリアしたら中断データを消す | I-03 |
| 5 | 保存の間隔 | 盤面が変わるたび、および画面が隠れるときに保存する | U-05, screen E-06 |

## 各画面 / 状態の詳細

画面は持たない。

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| 書き込みに失敗 | 表示なしで続行。前回の保存は残る |

## 未対応ケース

- 古い形式からの移行（必要になった時点で版ごとの読み込みを足す）
