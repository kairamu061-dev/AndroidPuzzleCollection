# 数独 概要

## 目的・背景

本アプリ最初の収録ゲーム。ルールがよく知られていて、問題を端末内で生成できるため
オフラインで無限に遊べる。問題データの同梱も配信も要らない。

## スコープ

### 作るもの

- 9×9 の数独。難易度 3 段階の問題を端末内で生成する
- 記入、メモ、消去、Undo/Redo、衝突の表示、経過時間、クリア判定
- 進行中の 1 ゲームの自動保存と再開

### 作らないもの

- 9×9 以外の盤面、変形ルール
- ヒント、答え合わせ、ミス回数の制限
- 統計、ランキング、デイリー問題、サウンド

## 制約

- 実行にネットワークを要しない
- 問題生成で画面を止めない

## 完了条件

- 全難易度で、唯一解を持つ問題を遊び始められる
- 最後のマスを埋めるとクリアになる
- アプリを閉じても続きから遊べる
- `docs/sudoku/*/test-cases.md` の自動テストが通り、E2E が実機で確認済みである
