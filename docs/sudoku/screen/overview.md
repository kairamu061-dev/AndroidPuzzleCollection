# 数独の画面 概要

## 目的・背景

エンジンとプレイ状態を、片手で遊べる画面にする。

## スコープ

### 作るもの

- 開始画面（続きから・難易度の選択）
- プレイ画面（盤面、数字ボタン、操作ボタン、経過時間）
- クリアの表示

### 作らないもの

- テーマの選択（端末のライト / ダーク設定に従う）
- 英語表示（文言は日本語のみ。`strings.xml` に集める）

## 制約

- 問題の生成とファイル入出力で UI スレッドを止めない
- 縦画面を主とし、横画面でも操作できる

## 完了条件

- `test-cases.md` の自動テストが通り、E2E が実機で確認済みである
