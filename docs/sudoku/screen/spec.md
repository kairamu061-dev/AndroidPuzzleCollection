# 数独の画面 仕様

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | 開始画面 | 難易度の選択。中断データがあれば「続きから」を出す | I-01, I-08 |
| 2 | 生成中の表示 | 問題ができるまで進捗の表示を出す | E-01 |
| 3 | 盤面の表示 | 初期配置・記入・メモ・太線を描く | I-02, I-03, E-02 |
| 4 | 入力の配線 | マス・数字・操作ボタンを状態の操作へつなぐ | I-02〜I-04 |
| 5 | 衝突の表示 | 衝突した数字を赤で描く | I-05 |
| 6 | 数字ボタンの残り個数 | 残りを小さく出し、0 で押せなくする | I-06 |
| 7 | 強調表示 | 選択中のマス、関連マス、同じ数字 | E-03 |
| 8 | 経過時間の表示 | `分:秒`。1 時間以上は `時:分:秒` | U-01, E-04 |
| 9 | クリアの表示 | 所要時間とボタン 2 つ | I-07, E-05 |
| 10 | 新規開始の確認 | 中断データがあるとき上書きの確認を出す | I-09 |
| 11 | 再開 | 「続きから」で盤面を戻す | I-08, E-06 |
| 12 | 横画面 | 盤面と操作を横に並べる | E-07 |

## 画面・操作フロー

全体の流れは `docs/sudoku/spec.md`。

## 各画面 / 状態の詳細

### 開始画面

- **表示内容**: 「続きから」（難易度と経過時間つき。中断データがあるときのみ）、難易度のボタン 3 つ
- **操作**: 「続きから」→ プレイ画面。難易度 → 確認（中断データがあるとき）→ 生成 → プレイ画面
- **遷移先**: 戻る操作でホーム

### プレイ画面

- **表示内容**: 難易度、経過時間、盤面、操作ボタン（戻す・進む・消す・メモ）、数字ボタン
- **操作**: マスを押して選択、数字ボタンで入力。メモのオン / オフは色で示す
- **遷移先**: 戻る操作で開始画面（保存済み）

### クリア

- **表示内容**: 「クリア」、難易度、所要時間
- **操作**: 「新しいゲーム」→ 開始画面、「ホームへ」→ ホーム。外側を押しても閉じない
- **遷移先**: 上記のとおり

### 色分け

| 対象 | 表現 |
|---|---|
| 初期配置 | 濃い文字 |
| 記入 | プライマリ色の文字 |
| 衝突 | エラー色の文字 |
| 選択中のマス | 濃い背景 |
| 関連マス | 薄い背景 |
| 同じ数字のマス | 中間の背景 |

## エラーケース

| 条件 | メッセージ / 挙動 |
|------|------------------|
| 生成中に戻る | 生成を取り消して開始画面へ |
