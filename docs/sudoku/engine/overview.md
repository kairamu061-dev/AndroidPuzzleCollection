# 数独エンジン 概要

## 目的・背景

問題を端末内で生成する。解が 2 つある問題は論理で解けないため、唯一解の保証が最重要。

## スコープ

### 作るもの

- 解法と解の個数の判定
- 手筋による難易度の判定
- シードで再現できる問題の生成

### 作らないもの

- 手筋の解説、ヒントの提示

## 制約

- Android に依存しない純粋な Kotlin で書く
- 生成はバックグラウンドで実行でき、取り消せる

## 完了条件

- 全難易度・多数のシードで唯一解かつ要求どおりの難易度の問題が作れる
- 生成時間が `test-cases.md` U-09 の上限に収まる

画面は持たない。
