# 数独エンジン 仕様

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | 解法 | 盤面の解を 1 つ求める | U-01 |
| 2 | 解の個数 | 解の個数を上限付きで数える。矛盾した盤面は 0 | U-02, U-03 |
| 3 | 難易度の判定 | 問題に必要な手筋から難易度を決める | U-07 |
| 4 | 問題の生成 | 指定の難易度・シードの問題を作る | U-04, U-05, U-06, U-08, U-09 |

## 難易度の定義

| 難易度 | 解くのに必要な手筋 |
|---|---|
| やさしい | 確定の手筋（naked single / hidden single）のみ |
| ふつう | 上に加えてブロックと行列の絞り込み（pointing / claiming）とペア（naked / hidden pair）。これらの少なくとも 1 つが必須 |
| むずかしい | 上の手筋だけでは解けない |

やさしいは初期配置を 36 個以上残す（空きマスが多すぎると単調な作業になるため）。

| 条件 | メッセージ / 挙動 |
