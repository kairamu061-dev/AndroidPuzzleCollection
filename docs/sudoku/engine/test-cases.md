# 数独エンジン テストケース

## ユニットテスト

| ID | テスト名 | 入力 / 条件 | 期待結果 | ステータス |
|----|---------|------------|---------|-----------|
| U-01 | 解法 | 既知の問題 | 既知の解と一致する | [x] |
| U-02 | 解の個数の区別 | 唯一解の問題 / 2 マス入れ替えで解が 2 つになる問題 | 1 / 2 | [x] |
| U-03 | 矛盾した盤面 | 同じ行に同じ数字 | 0 | [x] |
| U-04 | 生成: 解の妥当性 | 全難易度 × シード 50 個 | 解の全行・全列・全ブロックが 1〜9 | [x] |
| U-05 | 生成: 唯一解と整合 | U-04 と同じ | 解の個数が 1、初期配置が解と一致 | [x] |
| U-06 | 生成: 再現性 | 同じシード 2 回 / 異なるシード | 同一の問題 / 異なる問題 | [x] |
| U-07 | 難易度の判定 | 各段階の既知の問題 | 想定の段階（対照: 段階ごとに別の問題を用意し、常に同じ値を返す実装を落とす） | [x] |
| U-08 | 生成: 要求どおりの難易度 | U-04 と同じ | 判定が要求と一致。やさしいは初期配置 36 個以上 | [x] |
| U-09 | 生成: 所要時間 | 全難易度 × シード 50 個（JVM 上） | 1 件あたり最大 5 秒未満。試行回数も出力する | [x] |

## ステータス凡例

- `[ ]` 未実施
- `[~]` 実施中
- `[x]` 合格
- `[!]` 不合格
- `—` 対象外（差し替え・撤去など。理由を添える）

## 判定の注意

<!-- ここは消さずに残す。実際に判定を誤らせた形だけを書いてある -->

- **`0` を期待する項目には対照を置く。**「出なかった」は、**安定していた**のと
  **そもそも通っていない**のと区別が付かない。`1` になる場面を隣に置くか、
  数えている文字列が**実行ファイルの中にあること**を確かめる
- **「無いこと」を見る項目は、探し方が当たっているかを先に確かめる。**
  同じ探し方で「ある」ものを 1 つ挙げる。パスを間違えていれば、
  前も後も「無い」と出て、確認そのものが空になる
- **強い測り方に書き換える。**「見えていた」で通した項目は、次の回で弱いまま戻る。
  画素・ハッシュ・窓ハンドルで測れたなら、**その手順をここに書き写す**
- **1 つの操作を複数の窓口から見ている項目は、そう書く。**
  独立した N 件ではないので、「N 件通った」と数えない
