# 用語集

このプロジェクトで使用するドメイン固有の用語を定義する。
実装・設計・仕様書内で用語を使う際はここに定義されたものに統一する。

---

| 用語 | 定義 |
|------|------|
| ゲーム | 本アプリに収録するパズル 1 種類。最初の収録は数独 |
| ホーム | 収録ゲームの一覧を出す最初の画面 |
| 開始画面 | ゲームごとの、続きからと選択肢を並べる画面 |
| タイル | スライドパズルと 2048 の動かすコマ |
| ヒント | ノノグラムの行と列に並ぶ数字 |
| ×印 | ノノグラムで「塗らない」と決めたマスの印。完成判定には使わない |
| 問題集 | ノノグラムの同梱の絵 100 問 |
| なぞり | ノノグラムで押してから離すまでの 1 回の操作 |
| 盤面 | 9×9、計 81 マスの数独の面 |
| マス | 盤面の 1 区画。添字は左上を 0 とする 0〜80（`行 × 9 + 列`） |
| 行 / 列 | 横 / 縦に並ぶ 9 マス |
| ブロック | 太線で区切られた 3×3 の 9 マス |
| 関連マス | あるマスと同じ行・列・ブロックに属する、そのマス以外の 20 マス |
| 問題 | 初期配置と解の組 |
| 初期配置 | 問題として最初から埋まっている数字（変更不可）。マスを指すときは初期マス |
| 解 | 問題の唯一の完成形 |
| 記入 | プレイヤーが空きマスに入れた数字 |
| メモ | マスに小さく書く候補の数字。1 マスに複数書ける |
| 衝突 | 同じ行・列・ブロックに同じ数字が 2 つ以上ある状態。解との一致は見ない |
| 難易度 | やさしい / ふつう / むずかしい の 3 段階。定義は `docs/sudoku/engine/spec.md` |
| 手筋 | 候補を絞る人間向けの論理。難易度の判定に使う |
| クリア | 全マスが埋まり、解と一致した状態 |
| 中断データ | 再開のために端末へ保存した、進行中の 1 ゲーム分の状態 |
