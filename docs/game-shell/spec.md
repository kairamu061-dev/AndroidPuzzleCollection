# ゲーム共通部品 仕様

## 機能一覧

| # | 機能名 | 説明 | テストケース |
|---|--------|------|------------|
| 1 | 開始画面 | 続きからと選択肢を並べ、中断データがあれば上書きを確認する | sudoku screen I-01, I-09 |
| 2 | 時間つきの進行 | 読み込み → 開始 → 生成 → プレイ、表示中だけ時間が進む、終了で保存を消す | sudoku screen I-07, I-08 |
| 3 | 保存ファイル | 原子的に書き、順序を保って非同期で書く | I-01〜I-03 |
| 4 | 経過時間の書式 | `分:秒`、1 時間以上は `時:分:秒` | U-01 |
| 5 | タイマー | 一時停止できる計測 | U-02 |
