# ゲーム共通部品 概要

## 目的・背景

開始画面・経過時間・保存の書き込み・読み込みからプレイまでの状態遷移は全ゲームで同じになる。
ゲームごとに書くと直した場所だけ直る。数独のものを取り出して共有する。

## スコープ

### 作るもの

- `:game-common` の `PlayTimer`
- `:app` の開始画面、戻るボタン、確認ダイアログ、経過時間の書式、保存ファイル、時間つきゲームの ViewModel 基底

### 作らないもの

- ゲーム固有の盤面描画

## 制約

- 数独の振る舞いを変えない

## 完了条件

- 数独の既存テストが、共通部品へ差し替えた後も通る

## 画面イメージ

開始画面は `docs/sudoku/screen/overview.md` のものを共有する。
