# ホーム 概要

## 目的・背景

本アプリはパズルゲーム集であり、ゲームが増えても入口を 1 つに保つ必要がある。
起動直後にゲームの一覧を見せ、そこから各ゲームへ入る。

## スコープ

### 作るもの

- 収録ゲームの一覧画面
- 画面遷移の土台（ゲームを追加しても遷移の仕組みに手を入れずに済む形）

### 作らないもの

- 設定画面、統計、アカウント

## 制約

- ネットワークを使わない

## 完了条件

- 起動するとホームが出て、数独へ入れる。戻る操作でホームへ戻れる
- ゲームの追加が、一覧への 1 項目の追加で済む

## 画面イメージ

```
+---------------------------+
|  パズルコレクション       |
+---------------------------+
|  +---------------------+  |
|  | 数独                |  |
|  | 9×9 の定番パズル    |  |
|  +---------------------+  |
+---------------------------+
```
